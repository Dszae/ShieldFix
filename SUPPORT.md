# Getting help

| You want to…                    | Go to                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------- |
| Install or use ShieldFix        | [README → Install](README.md#-install) and the **Help** page inside the ShieldFix dashboard |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/Dszae/ShieldFix/discussions)                        |
| Report a wrong detection        | [False positive](https://github.com/Dszae/ShieldFix/issues/new?template=false_positive.yml) |
| Report a wall ShieldFix missed  | [Missed warning](https://github.com/Dszae/ShieldFix/issues/new?template=missed_warning.yml) |
| Report a bug                    | [Bug report](https://github.com/Dszae/ShieldFix/issues/new?template=bug_report.yml)         |
| Report a security vulnerability | Privately, via [SECURITY.md](SECURITY.md)                                                   |

Before opening an issue, open **Diagnose** in the ShieldFix popup — its output answers most “why” questions, and
including it in a report makes the problem much faster to fix.
